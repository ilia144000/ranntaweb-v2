What Is RANNTA Agent Firewall?

RANNTA Agent Firewall is an external authorization and risk-control layer between autonomous AI agents and financial execution systems. Its operating model is simple: the agent proposes, the owner defines the rules, the firewall verifies, and the wallet executes.

The design gives an AI agent limited financial authority without giving it unrestricted possession of the wallet. The wallet remains the execution boundary.

V0.8.0 Production Capabilities

  • Tenant-isolated API access for B2B integrations and paid technical pilots.
  • Scoped Agent Sessions bound to owner-defined policy and agent identity.
  • Agent Ed25519 proofs for signed autonomous actions.
  • Owner ML-DSA-65 policy authorization for post-quantum-oriented policy verification.
  • Replay protection using monotonic nonces and single-use authorization consumption.
  • Per-transaction, daily and session spending limits enforced independently by the firewall.
  • Usage metering, quotas and customer audit logs for commercial API operation.
  • TypeScript and Python SDKs for server-side integration.

API Keys Do Not Replace Wallet Authorization

Commercial API keys identify the customer account. They do not grant possession of wallet keys and do not replace the cryptographic authorization required for financial execution. The current model keeps customer authentication, agent-action authentication, owner policy authorization and wallet execution authorization as separate trust boundaries.

Built for Autonomous Finance Integrations

RANNTA Agent Firewall is intended for wallets, AI trading agents, treasury systems, payment agents and other autonomous finance applications that need policy-controlled execution. The production service now supports tenant provisioning, API credentials, usage accounting and audit visibility for integration pilots.
