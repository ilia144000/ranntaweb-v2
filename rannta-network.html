RANNTA X-Chain

RANNTA X-Chain is the independent blockchain network of the RANNTA ecosystem. It is separate from the RANNTA Jetton issued on The Open Network (TON).

The network uses Chain ID 13113 (0x3339) and the native currency RANNTA Core X (RNTX). Public JSON-RPC and block-explorer infrastructure are available for network access and verification.

RANNTA X-Chain provides an EVM-compatible JSON-RPC surface for wallet, transaction, contract and application integration while the broader RANNTA interoperability and post-quantum security stacks continue to expand.

Post-Quantum Security Architecture — ML-DSA-65 · HybridRequired · Fail-Closed

RANNTA is engineering post-quantum security into the authorization path itself. The architecture combines classical authorization with ML-DSA-65, standardized in NIST FIPS 204, and applies explicit HybridRequired policy semantics to security-critical operations.

RANNTA protocol engineering extends this model into validator proposal, vote and finality authorization. When HybridRequired protection is active, classical-only authorization is rejected instead of being silently accepted. The same model is exported to external production systems through the live RANNTA PQ Cloud.

  • ML-DSA-65 post-quantum verification aligned with NIST FIPS 204.
  • HybridRequired policy combining classical and post-quantum authorization.
  • Fail-closed enforcement on protected authorization paths.
  • Validator proposal / vote / finality authorization integrated into RANNTA consensus engineering.
  • Canonical payload binding, key versioning and replay resistance as part of the authorization model.
  • RANNTA PQ Cloud for exchanges, treasuries, validators, blockchains and digital-asset infrastructure.
  • Next protocol frontier: canonical PQ state, broader distributed validator quorum, ML-KEM transport and PQ authorization aggregation.

Post-quantum security should not be a feature of a signature. It should be a property of the authorization path.

Public Node Participation — RANNTA Core v0.1.6

Public node participation is now open. RANNTA Core v0.1.6 allows Windows 10/11 64-bit users to run an independent RANNTA X-Chain Mainnet full node, synchronize local chain state, monitor node health and bind a reward wallet through a secure message-signing flow.

  • Independent per-install node identity and TLS enrollment.
  • Full Mainnet synchronization and live local/network height monitoring.
  • Secure reward-wallet binding for MetaMask and compatible EIP-1193 EVM wallets.
  • No wallet private key or seed phrase is requested or stored.
  • Qualified uptime, synchronization health, challenge performance and wallet verification are measured from participation.
  • Current qualification target: at least 6 qualified hours per day for at least 20 qualified days in a month.
  • Eligible early-node participation recorded during the measurement period is intended to be included in the RNTX reward settlement process when manual distribution is activated.

Network Status

The X-Chain core network, public RPC compatibility layer, explorer, production node services and public-node enrollment path are implemented and publicly reachable. The network is no longer merely an emerging architecture or unlaunched concept.

Public Windows node software is released for independent-node participation. Production node identity, heartbeat monitoring, reward qualification telemetry and owner-controlled settlement administration are active. Reward accounting currently runs in Shadow Mode, meaning qualification and reward amounts are recorded while on-chain transfers remain under manual owner approval.

Hybrid post-quantum authorization with ML-DSA-65 is part of the active RANNTA security architecture. Expanded validator decentralization, canonical PQ state, ML-KEM transport, bridge infrastructure, native liquidity and ecosystem integrations remain separate growth stages and are announced independently after implementation and verification.

Network Identity

The TON-based RANNTA Jetton remains the first public RANNTA ecosystem asset. RNTX is the native currency identity of RANNTA X-Chain. These assets and network layers must not be conflated.
