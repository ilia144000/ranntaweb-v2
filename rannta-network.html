RANNTA X-Chain

RANNTA X-Chain is the independent blockchain network of the RANNTA ecosystem. It is separate from the RANNTA Jetton issued on The Open Network (TON).

The network uses Chain ID 13113 (0x3339) and the native currency RANNTA Core X (RNTX). Public JSON-RPC and block-explorer infrastructure are available for network access and verification.

RANNTA X-Chain provides an EVM-compatible JSON-RPC surface for wallet, transaction, contract and application integration while the broader RANNTA interoperability stack continues to expand.

Network Status

The X-Chain core network, public RPC compatibility layer and explorer are implemented and publicly reachable. The network is no longer described as merely an emerging architecture or an unlaunched concept.

Additional decentralization, validator expansion, bridge infrastructure, native liquidity and ecosystem integrations are separate growth stages and do not change the current identity of X-Chain as an implemented blockchain network.

Network Identity

The TON-based RANNTA Jetton remains the first public RANNTA ecosystem asset. RNTX is the native currency identity of RANNTA X-Chain. These assets and network layers must not be conflated.
