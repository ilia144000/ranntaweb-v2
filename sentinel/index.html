WHAT THIS TOOL IS FOR

A pre-interaction risk check for tokens and smart contracts

Sentinel is designed to answer practical questions before you interact with a token: Can supply be changed? Can transfers be paused or blacklisted? Is the contract upgradeable? Are buy/sell restrictions or taxes reported? How much observable liquidity exists, and is supply concentrated in a small number of addresses?

WHY BITCOIN IS NOT IN THE SELECTOR

Bitcoin addresses are a different type of risk analysis

This scanner evaluates token contracts and token mints. Bitcoin does not use ERC-20-style token contracts or Solana mint accounts; it uses UTXO addresses and transaction history. A meaningful Bitcoin scanner must analyze address transactions, UTXO flows, counterparties and known-risk attribution. That is a separate address-intelligence module, not the same contract scanner.

Current scope: token / smart-contract risk — not wallet reputation or Bitcoin address scoring.

Sentinel reports observable evidence. Unknown data is shown as unknown and is not treated as safe. It does not guarantee safety or provide financial advice.
